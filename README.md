# مين الأسبق

لعبة تحدي جماعية بين فريقين على شاشة واحدة، مبنية بـ **Laravel 12 + Filament 3 + Livewire 3**.

## فكرة اللعبة

- كل فريق يختار **٣ فئات**، فتصير اللوحة ٦ فئات × ٦ أسئلة = **٣٦ سؤال**.
- كل فئة فيها سؤالين لكل مستوى: **٢٠٠ / ٤٠٠ / ٦٠٠** نقطة.
- الفريقان يتناوبان: الفريق صاحب الدور يختار سؤالاً وعنده **٦٠ ثانية**.
- إذا ما عرف الإجابة، الفريق الثاني عنده **٣٠ ثانية للسرقة**.
- الدور ينتقل للفريق الثاني بعد كل سؤال، سواء انجاوب أو لا.
- اللعبة تنتهي لما تخلص اللوحة، والأعلى نقاطاً يفوز.

### وسائل المساعدة

كل فريق يستخدم كل وسيلة مرة وحدة باللعبة، وعلى دوره فقط:

| الوسيلة | تأثيرها |
|---|---|
| ×٢ دبل | نقاط السؤال تتضاعف إذا جاوب الفريق نفسه صح |
| +٣٠ وقت إضافي | ٣٠ ثانية زيادة على المؤقت |
| 🔒 قفل | الفريق الثاني ما يقدر يسرق السؤال |

### أدوات المقدّم

- **إظهار الإجابة**، ثم اختيار مين جاوب صح: الفريق الأول أو الثاني أو ولا أحد.
- **رجوع للوحة بدون احتساب**، لو انفتح سؤال بالغلط.
- **تصحيح النتيجة** بزيادة أو نقص ١٠٠ نقطة، من أزرار خفيفة على لوحة النتائج.
- **إيقاف المؤقت وتشغيله** بالضغط على دائرة المؤقت.

## التشغيل

### على GitHub Codespaces (الأسهل)

1. من صفحة الريبو اضغط **Code** ثم **Codespaces** ثم **Create codespace on main**.
2. انتظر حتى يخلص التجهيز التلقائي (٥ لـ ٨ دقائق أول مرة). الـ Codespace بيبني بيئة PHP 8.3 فيها كل الإضافات، ويثبّت المكتبات، وينشئ قاعدة البيانات مع الأسئلة التجريبية.
3. بالـ terminal شغّل `php artisan serve`، وافتح البورت **8000** من تبويب **Ports**.

إذا التجهيز ما اشتغل لأي سبب، شغّله يدوياً بـ `bash .devcontainer/setup.sh`.

### على جهازك (PHP 8.2+ مع إضافتي intl و zip، و Composer، و Node 20+)

```bash
git clone https://github.com/sariazad/Faster.git && cd Faster
bash .devcontainer/setup.sh
php artisan serve
```

| الرابط | الصفحة |
|---|---|
| `/` | الرئيسية |
| `/play/new` | إعداد لعبة جديدة |
| `/admin` | لوحة التحكم (`admin@example.com` / `password` — غيّرها من `.env` قبل الـ seed) |


## بنك الأسئلة

اللعبة تجي مع **٦٠ فئة** فيها **٨٤٥ سؤال**، وكل فئة فيها ٤ أسئلة على الأقل لكل مستوى (٢٠٠ / ٤٠٠ / ٦٠٠)، حتى ما تتكرر الأسئلة بسرعة بين الألعاب.

- **الأسئلة:** `database/seeders/data/question-bank.csv` بنفس صيغة الاستيراد، فتقدر تفتحه وتعدّله بـ Excel.
- **الأيقونات والأوصاف والترتيب:** `database/seeders/data/categories.json`.
- **لإضافته لقاعدة بيانات موجودة:** `php artisan db:seed --class=QuestionBankSeeder`. الأمر آمن لو تكرر: ما بيكرر الأسئلة الموجودة، وما بيغيّر تعديلاتك على الفئات.

الفئات: دينية (القرآن، قصص الأنبياء، إسلاميات، مكة والمدينة)، سعودية وخليجية (السعودية، الرياض، بوابة الخليج، الهلال، النصر، الاتحاد، كرة قدم سعودية)، جغرافيا (دول وعواصم، أعلام، عجائب الدنيا، مطارات)، رياضة (كأس العالم، دوري الأبطال، الكلاسيكو، فورمولا 1، NBA)، أفلام ومسلسلات (هاري بوتر، سيد الخواتم، مارفل، دي سي، فريندز، بريكنج باد، لا كاسا دي بابيل، سكويد قيم، سترينجر ثينقز، الأوسكار)، أنمي وكرتون (ون بيس، ناروتو، هجوم العمالقة، ديث نوت، دراغون بول، كرتون الطيبين)، وتقنية وعامة (أبل، ذكاء اصطناعي، ماينكرافت، سيارات، ماركات عالمية، حيوانات، أوائل، صح أو غلط، وغيرها)، وفن سعودي (محمد عبده، طلال مداح، عبادي الجوهر، رابح صقر، عايض، مزعل فرحان، أغاني سعودية، مسلسلات سعودية، فن سعودي).

### كيف تنختار الأسئلة لكل لعبة

- **دورة على البنك:** كل سؤال إله عدّاد ظهور، والسحب بيفضّل الأسئلة اللي ما ظهرت أو ظهرت أقل، وبعدها الأقدم ظهوراً. يعني السؤال ما بيرجع قبل ما تنلعب باقي أسئلة نفس الفئة والمستوى.
- **ما في تكرار باللعبة الوحدة:** لا نفس السؤال، حتى لو نصه موجود بفئتين، ولا سؤالين إلهم نفس الجواب، طالما في بديل.
- **عشوائية:** بين الأسئلة اللي إلها نفس عدد الظهور، وبترتيبها على اللوحة.
- **حذف المكرر:** زر «حذف المكرر» بصفحة الأسئلة، أو الأمر `php artisan questions:dedupe`، وبتقدر تضيف `--dry-run` للمعاينة بدون حذف. الأداة بتعتبر السؤالين نفس الشي إذا نصهم واحد بعد تجاهل التشكيل والهمزات وعلامات الترقيم. وبتحتفظ بنسخة وحدة، وبتفضّل النسخة اللي فيها صور أو صوت، والألعاب السابقة ما بتتأثر.
- **من لوحة التحكم:** عمود «مرات الظهور» بصفحة الأسئلة، وزر «تصفير عدّاد الظهور» لما بدك البنك يرجع كأنه جديد، مثلاً قبل فعالية بجمهور جديد.

> أسئلة الفرق والبطولات فيها معلومات بتتغير مع الوقت، متل عدد الألقاب أو المدرب الحالي. لهيك صياغتها مربوطة بسنة محددة، مثلاً «حتى 2024».

## لوحة التحكم

- **الفئات:** اسم، إيموجي، صورة، ترتيب بالسحب، وعمود يوضّح إذا كانت الفئة **جاهزة للعب** (فيها سؤالين مفعّلين على الأقل لكل مستوى). أسئلة الفئة تنضاف من داخل صفحتها مباشرة.
- **الأسئلة:** فلترة حسب الفئة والنقاط، وصورة اختيارية لكل سؤال.
- **استيراد CSV:** الأعمدة هي `الفئة, النقاط, السؤال, الإجابة`، ويمكن كتابة عناوين الأعمدة بالإنجليزي أيضاً. الفئات الجديدة تنضاف تلقائياً، والأسئلة المكررة تتجاهل. النموذج موجود في `public/samples/questions-template.csv`. من Excel احفظ الملف بصيغة **CSV UTF-8**.
- **الألعاب:** سجل الألعاب ونتائجها، مع إمكانية فتح أي لعبة جارية.

## البنية

```
app/Models/Game.php                 ← كل قواعد اللعبة (start, open, useHelper, award, finish)
app/Livewire/GameSetup.php          ← أسماء الفريقين واختيار الفئات
app/Livewire/GamePlay.php           ← اللوحة + شاشة السؤال + النتيجة
app/Services/QuestionCsvImporter.php
app/Filament/Resources/             ← الفئات، الأسئلة، الألعاب
resources/views/livewire/           ← واجهات اللعبة (RTL، Tailwind)
```

حالة اللعبة كلها محفوظة بقاعدة البيانات، يعني تحديث الصفحة ما يضيّع شي. الإعدادات (عدد الفئات والوقت والمستويات) ثوابت في أعلى `Game.php`.

## المرحلة الجاية: Pusher

إعدادات Pusher موجودة بـ `.env.example`. لتفعيلها، مثلاً لشاشة عرض منفصلة أو لاستخدام الجوالات كأزرار buzzer:

```bash
php artisan install:broadcasting   # اختر Pusher
```

بعدها غيّر `BROADCAST_CONNECTION=pusher`، وأطلق events من `Game::award()` و`Game::open()`.
